NOTES FROM BUILDING THIS

What is the network actually doing?

This is the mental model that helped me understand the code. The real calculations happen one number at a time.

01 / THE BIG PICTURE

An image goes in. A guess comes out.

At the start, the network has no idea what a handwritten 7 looks like. I give it an image and ask it to produce ten scores: one for each possible digit, from 0 through 9. At first those scores are mostly guesses. Training is the process of making those guesses less wrong.

02 / THE LAYERS

Why have a hidden layer?

The input layer is just the pixel values. The output layer represents the ten possible answers. The hidden layer sits in between and gives the network room to combine pixels into more useful patterns — for example, edges, curves, loops, and the way strokes meet.

Each neuron receives numbers from the previous layer, multiplies them by weights, adds a bias, and applies an activation function. It is not assigned a human-readable feature; those useful patterns emerge as the weights change during training.

Input layerThe 196 brightness values from the image.
Hidden layerThe 64 intermediate calculations that combine those values.
Output layerTen scores that become probabilities for digits 0–9.
ReLUTurns negative values into zero and keeps positive values.
SoftmaxTurns the ten output scores into values that add up to 1.

03 / PARAMETERS

The numbers the network learns.

Most of what the model learns is stored in its weights and biases. They start with small random values. During training, the network keeps nudging them so that the correct digit gets a higher score next time.

ParameterWhat it means here
WeightsHow strongly one neuron influences the next. These are the main learned values.
BiasesAn extra value added to a neuron's weighted input, shifting when it activates.
Learning rateHow large each update is. Too high can make learning unstable; too low can make it slow.
Batch sizeHow many examples are used to calculate one update. This project uses 32.
EpochOne pass through the full training set.

04 / THE TRAINING LOOP

How a wrong answer turns into an update.

This is the loop I wanted to understand rather than treat as a black box. The model makes a prediction, measures how far it was from the label, and uses that error to work out which weights should change.

  1. Forward passPixels move through the network. The output layer produces ten probabilities.
  2. Calculate the lossThe correct label is compared with the prediction. A confident wrong answer gets a larger penalty.
  3. BackpropagationThe error is traced backwards to calculate how much each weight and bias contributed.
  4. Update the parametersGradient descent adjusts the weights. Momentum helps updates keep moving in a consistent direction.
  5. RepeatThe network sees more batches, then another epoch. I check accuracy on examples it did not train on.
One distinction worth remembering

Training accuracy and test accuracy are not the same thing. A model can get very good at examples it has already seen without being equally good at new ones. That is why DigiDetect keeps a separate test set and reports its accuracy.
